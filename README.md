# FASTag Toll Management System

A Java-based, console-driven application designed to simulate automated toll collection.

## Member 1 - Customer & Vehicle Management
Contains:
- **Models**: `User`, `Admin`, `Vehicle`, `Car`, `Bike`, `Truck`
- **DAO**: `UserDAO`, `VehicleDAO`
- **Services**: `AuthService`, `UserService`, `VehicleService`
- **UI**: `CustomerMenu`
- **Exceptions**: `InvalidFastagException`

See [README_MEMBER1.md](README_MEMBER1.md) for detailed integration specifications and database schemas.
